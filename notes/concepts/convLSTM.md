# convLSTM

**Convolutional Long Short-Term Memory**
- Combines [[convolutional-neural-network]] and [[LSTM]]]
- Represents the combination of feature extraction from [[convolutional-neural-network]] and memory cells which can proces sequences of images (e.g.video, satellite image sequence)

- Replaces flattening of [[LSTM]] with [[convolution]]
- Retains spatial relationship of neighboring input image cells
